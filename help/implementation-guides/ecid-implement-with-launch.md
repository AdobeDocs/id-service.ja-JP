# データ収集タグを使用した実装{#implement-with-launch}

タグは、訪問者ID サービスを設定、デプロイ、および他のCX エンタープライズ ソリューションと統合するために使用される主なツールです。

## データ収集タグについて {#section-611711602854464ea351a4af80a8dafe}

Adobe Experience Platform Data Collectionの[Tags](https://experienceleague.adobe.com/docs/experience-platform/tags/home.html?lang=ja)は、Adobe CX Enterpriseに組み込まれている次世代のAdobe タグ管理機能です。 タグを使用すると、クライアントは次のことができます。

* _拡張機能_&#x200B;と呼ばれる統合機能を使用してクライアントサイドの web 製品をデプロイします。
* 他のベンダーやアドビのマーケティング製品と広告製品の間で、一貫してデータをキャプチャ、定義、管理、共有します。
* タグは、条件を評価してアクションを実行し、クライアントサイドのライブラリと製品を効率的かつ効果的にデプロイする、高度なJavaScript配信システムです。 タグは、拡張機能を管理および構築するための高度にスケーラブルなアプローチと、Adobe CX Enterpriseとのプログラマティックなインタラクションのための堅牢なAPI セットを提供します。
