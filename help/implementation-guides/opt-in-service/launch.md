# タグを使用したオプトインの設定 {#configuring-opt-in-with-launch}

タグを使用して、オプトイン用のCX エンタープライズソリューションを簡単に有効にできます。

## タグを使用したオプトインシナリオの設定 {#section-8aa1b58bf8374c938aa8cfdeddbad6ff}

Adobe Experience Platform Data Collectionの[Tags](https://experienceleague.adobe.com/docs/experience-platform/tags/home.html?lang=ja)を使用すると、Adobe ソリューションを使用したオプトインシナリオの設定と設定が簡単になります。 Analytics、Target、Audience Managerなどの一部のCX Enterprise ソリューションを有効にすることで、CX Enterprise ソリューションに対する訪問者のオプトイン同意を簡単に収集できます。

**[!UICONTROL Experience Cloud ID Service] タグ拡張機能を設定**

[!UICONTROL Experience Cloud ID Service] タグ拡張機能がまだインストールされていない場合は、プロパティを開き、*拡張機能* > *カタログ*&#x200B;をクリックし、[!UICONTROL Experience Cloud ID Service] タグ拡張機能にカーソルを合わせて&#x200B;*インストール*&#x200B;をクリックします。

拡張機能を設定するには、「*拡張機能*」タブを開き、拡張機能の上にカーソルを置きます。 次に、「*設定*」をクリックします。

追加参照情報については、[!UICONTROL Experience Cloud ID Service] タグ拡張機能[overview](https://experienceleague.adobe.com/docs/experience-platform/tags/extensions/client/id-service/overview.html?lang=ja) （訪問者ID サービスを実装する拡張機能）を参照してください。
