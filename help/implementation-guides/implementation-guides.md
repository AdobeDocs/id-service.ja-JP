# 実装ガイド

Visitor ID サービスの標準および非標準の実装の手順とコードサンプル。

>[!IMPORTANT]
>
>これらの手順を開始する前に、必ず[訪問者ID サービス要件](../reference/requirements.md)を読んで理解してください。

## 標準的な実装

標準的な実装では、[ タグ ](https://experienceleague.adobe.com/docs/experience-platform/tags/home.html?lang=ja)を使用して訪問者ID サービスを開始し、他のCX エンタープライズ ソリューションと統合するのに役立ちます。 訪問者ID サービスを実装する場合は、タグを使用することを強くお勧めします。
